# AgenticQ Examples

These projects validate AgenticQ scanning, recommendations, and scaffolding.

## python_agenticq_demo
- FastAPI demo with OpenAPI markers and pytest config.
- Scaffolded plugins: python-development, unit-testing, backend-development.

## portfolio_site
- Static portfolio UI built to exercise UI design skills.
- Scaffolded plugins: ui-design, javascript-typescript, frontend-mobile-development.

## devops_infra
- Docker, Kubernetes, Terraform, and CI markers for DevOps detection.
- Scaffolded plugins: cloud-infrastructure, kubernetes-operations, cicd-automation.
